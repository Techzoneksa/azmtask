# ستيكر واتساب — «الوقت ينفذ»

ستيكر متحرك مربع بمقاس **512×512** (المقاس الرسمي لملصقات واتساب)، بتصميم ساعة رملية
يتساقط رملها مع نبض النص وتحوّل لونه إلى الأحمر كلما اقترب الوقت من النفاد.

## الملفات

| الملف | الصيغة | الاستخدام |
|---|---|---|
| `alwaqt-yanfad.gif` | GIF متحرك (24 إطارًا، حلقة لا نهائية) | للمشاركة المباشرة أو تطبيقات صنع الملصقات |
| `alwaqt-yanfad.webp` | WebP متحرك | الصيغة الأصلية لملصقات واتساب المتحركة |
| `make_sticker.py` | سكربت Python | لإعادة توليد الستيكر أو تعديله |

## إضافته إلى واتساب

1. انقل ملف `alwaqt-yanfad.gif` إلى هاتفك.
2. افتح أي تطبيق لصنع الملصقات (مثل Sticker Maker) وأضِف الملف كملصق متحرك.
3. أو أرسل الـ GIF مباشرة في المحادثة.

## إعادة التوليد

```bash
pip install pillow
# ضع خط Cairo.ttf بجانب السكربت (من Google Fonts)
python3 make_sticker.py
```
