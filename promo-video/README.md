# Prime POS — فيديو ترويجي (ستوري 9:16)

فيديو موشن جرافيك ترويجي لنظام **Prime POS** موجّه لأصحاب المطاعم والكافيهات.

- **المقاس:** 1080×1920 (ستوري عمودي 9:16)
- **المدة:** 30 ثانية — 30 إطارًا/ثانية
- **اللغة:** العربية الفصحى (اتجاه RTL سليم، خط Tajawal)
- **الألوان:** كحلي داكن، أزرق، أبيض، ولمسات ذهبية
- **الصوت:** تعليق صوتي عربي رجالي (صوت "حامد" السعودي — Microsoft Neural TTS) + موسيقى إلكترونية حماسية 128 BPM مُولَّدة برمجيًا
- **الناتج النهائي:** `output/prime-pos-promo-1080x1920.mp4` (H.264 + AAC، جاهز لإنستغرام وسناب شات)

## المشاهد

| الزمن | المشهد |
|---|---|
| 0–4 ث | أجواء مطعم/كافيه مزدحم — «إدارة مطعمك أصبحت أسهل» |
| 4–9 ث | واجهة الكاشير: إضافة منتجات وإصدار فاتورة — «طلبات أسرع • فواتير دقيقة • خدمة أفضل» |
| 9–15 ث | انتقال الطلب لشاشة المطبخ وتحديث الحالة (جديد ← قيد التحضير ← جاهز) |
| 15–22 ث | لوحة التحكم: المبيعات، الطلبات، الأكثر مبيعًا، الفروع، الأرباح، المخزون، الموظفون، التقارير |
| 22–27 ث | متابعة عدة فروع من الجوال — «تابع أعمالك من أي مكان» |
| 27–30 ث | الشعار الختامي + «اطلب تجربتك الآن» |

## الملفات

- `index.html` — مصدر الموشن جرافيك (مشاهد CSS keyframes قابلة للتحريك الزمني عبر `window.seek(t)`)
- `render.mjs` — التقاط الإطارات عبر Playwright/Chromium (1080×1920)
- `voiceover.py` — توليد التعليق الصوتي العربي (edge-tts، صوت `ar-SA-HamedNeural`)
- `voiceover.srt` — نص التعليق الصوتي بتوقيتاته
- `music.mjs` — توليد المقطع الموسيقي (WAV مُخلَّق برمجيًا)
- `encode.sh` — دمج الصوت (مع Ducking تلقائي تحت التعليق) وترميز MP4 النهائي
- `fonts/` — خط Tajawal (خمسة أوزان)
- `audio/` — مقاطع التعليق الصوتي والموسيقى والمزيج النهائي

## إعادة الإنتاج

```bash
npm i playwright-core            # مرة واحدة
python3 -m pip install edge-tts  # مرة واحدة

python3 voiceover.py             # توليد التعليق الصوتي
node music.mjs                   # توليد الموسيقى
node render.mjs frames 30        # التقاط 900 إطار
FF=/path/to/ffmpeg/bin ./encode.sh frames output/prime-pos-promo-1080x1920.mp4
```

ملاحظة: التعليق الصوتي مُولَّد آليًا بجودة عالية؛ ويمكن استبداله بتسجيل استوديو لاحقًا بنفس التوقيتات في `voiceover.srt`، وكذلك استبدال الموسيقى بمقطع مرخَّص تجاريًا عند الرغبة.
